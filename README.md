# Mantenimiento 360

Prototipo interactivo (web + app móvil) de un sistema digital de gestión de mantenimiento de maquinaria pesada.
Proyecto de Innovación Tecnológica – CETEMIN, fase Prototipar (Design Thinking).

Es una sola página HTML sin dependencias: abre `index.html` en el navegador.

## Qué simula
- Plataforma web con perfiles: Técnico, Supervisor y Superintendencia.
- App móvil (Android, iPhone y Tablet) para técnicos.
- Alertas, órdenes de trabajo, checklists, historial, códigos QR y reportes conectados entre sí.

Los datos son de ejemplo.
